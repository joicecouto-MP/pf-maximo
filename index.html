Como publicar no GitHub

Passo 1 — Salvar o arquivo HTML
Salve esta página como index.html na raiz do seu repositório GitHub.
Passo 2 — Criar arquivo de dados
Exporte o JSON e salve como data.json na mesma pasta. O dashboard carregará automaticamente ao detectar o arquivo.
Passo 3 — Ativar GitHub Pages
Em Settings → Pages, selecione a branch main e pasta / (root). O dashboard ficará disponível em https://[usuário].github.io/[repositório]
Passo 4 — Atualizar dados
Para atualizar, exporte um novo JSON, substitua o data.json no repositório e faça commit. O histórico de versões fica registrado automaticamente no git.

Guia de uso — Máximo & Diário de Bordo

Para pontos focais
Passo 1 — Inscrição: Acesse "Inscrição Semanal", escolha a semana disponível e preencha seus dados.
Passo 2 — Registro: Em "Atividades / Dúvidas", registre o tema, categoria e solução proposta.
Passo 3 — Diário: Registre reuniões, decisões e próximos passos no Diário de Bordo.
Passo 4 — Tarefas: Crie e acompanhe tarefas no gerenciador Kanban da equipe.
Para gestoras — Joice e Natália
Validação: Selecione "Gestora" no seletor de perfil. O painel de validação aparece em "Atividades / Dúvidas".
Relatório: Use "Relatório de Dúvidas" para identificar temas recorrentes e indicar treinamentos.
Exportação: Acesse "Exportar Dados" para baixar CSV/JSON e manter histórico versionado.
